# Creative and multipurpose sites

Use for creative studios, agencies, designers, portfolios, campaign-led businesses, and configurable brand sites. A multipurpose demo is a source of page families, not permission to combine every family into one site.

## Select one operating mode

- **Agency/studio:** work and point of view sell the engagement.
- **Corporate:** capabilities, governance, scale, and contact path sell trust.
- **Personal/portfolio:** identity, selected work, role, and availability sell the person.
- **Product/startup landing:** problem, product evidence, adoption path, and proof sell one offer.
- **Campaign/experimental:** a single idea and distinctive interaction lead; keep the conversion path legible.

## Required decisions

1. Choose the mode before choosing sections.
2. Name the one audience and the one action.
3. Decide whether work, expertise, product evidence, or brand expression is the primary proof.
4. Use only page families that serve that proof.

## Useful sequences

**Agency/studio:** thesis or selected work → capabilities through examples → process → named team → contact.

**Portfolio:** identity/role → selected work → project detail with contribution and outcome → about → availability/contact.

**Corporate:** proposition → capability groups → industries/use cases → evidence/governance → contact route.

**Product landing:** problem/outcome → product demonstration → use cases → proof → adoption/pricing → CTA.

## Structural guidance

- Prefer Portfolio Grid or Split Studio when real work is the proof.
- Prefer Marquee Hero or Manifesto only when the brand has a defensible point of view.
- Prefer Workbench when real product captures exist.
- Experimental interaction must not conceal navigation, focus state, or the primary action.
- A large collection of page types may justify N11 Mega-menu; a small studio does not.

## Anti-patterns

- Do not mix agency, shop, startup, portfolio, and corporate sections into one generic long page.
- Do not use project thumbnails without role, scope, or outcome.
- Do not substitute abstract 3D objects for proof of actual work.
- Do not label stock portraits as a real team.
- Do not let animation delay access to content or make the cursor the only affordance.
- Do not repeat `creative solutions`, `innovative ideas`, or `we build experiences` without domain-specific meaning.
